# Revised Methodology and Mathematical Definitions

## 1. Data modes

- `synthetic`: deterministic offline development data.
- `public`: adjusted-close data from the configured cache or `yfinance`; failure is explicit.
- `auto`: attempts public data and records an explicit fallback reason if synthetic data are used.

## 2. Time split and leakage control

The raw time index is divided chronologically into training/pair-selection, validation, and test windows. If labels look forward by `H` days, the final `H` observations before each boundary are purged. An additional embargo removes the configured number of observations immediately after each boundary.

Pair selection, cointegration estimation, and hedge-ratio estimation use only the training window. The fitted intercept and hedge ratio are frozen for validation and testing.

## 3. Cointegration and multiple testing

For candidate assets `A` and `B`, the training-period log-price regression is:

```text
log(P_A,t) = alpha + beta log(P_B,t) + epsilon_t
```

The spread is:

```text
s_t = log(P_A,t) - alpha - beta log(P_B,t)
```

The pipeline reports:

1. return correlation;
2. ADF tests on log-price levels and first differences to assess whether both series are plausibly I(1);
3. Engle-Granger cointegration p-value;
4. ADF p-value on the fitted residual spread using the same regression orientation;
5. Benjamini-Hochberg FDR-adjusted Engle-Granger p-value;
6. estimated spread half-life.

When configured conservatively, a pair must satisfy the correlation threshold, both cointegration diagnostics, the I(1) checks, and FDR control. If no pair passes and `allow_best_available` is enabled, the output explicitly marks the selected pair as provisional.

## 4. Lagged features

All model predictors are shifted by one trading day. The current spread is retained only for realized PnL and label outcomes.

### Rolling z-score

```text
z_t = (s_t - mean_w(s)_t) / std_w(s)_t
```

The decision uses `z_(t-1)` when the configured lag is one day.

### Half-life

Within a rolling window, the spread change is regressed on the lagged spread:

```text
Delta s_t = a + b s_(t-1) + u_t
half_life = -ln(2) / b, for b < 0
```

### Deviation persistence

Deviation persistence is the lagged count of consecutive observations for which:

```text
|z_t| >= persistence_threshold_z
```

### Regime-stress proxy

The proxy is the equal-weighted average of:

1. the rolling historical percentile of spread volatility; and
2. the rolling historical percentile of negative return correlation.

```text
stress_t = 0.5 percentile(volatility_t) + 0.5 percentile(-correlation_t)
```

Only observations inside the trailing stress window are used.

## 5. Economic labels

Labels are created only when the lagged signal satisfies the entry threshold. The trade direction is opposite the sign of the z-score. A signal is labeled `1` when:

- convergence occurs before the stop-loss;
- convergence occurs within the configured horizon; and
- the directionally signed spread return is positive after four asset-leg costs: two legs at entry and two at exit.

The output records the holding time, gross return, net return, and exit reason.

## 6. Model selection

The data are divided into purged training, validation, and test signal sets.

- Models are fitted on training signals.
- The probability threshold is chosen on validation signals.
- The best model is selected using the configured validation metric only.
- Each model is refitted on training plus validation data.
- All final classification and trading metrics are reported on the untouched test period.

The pipeline reports accuracy, balanced accuracy, precision, recall, F1, AUC, Brier score, class prevalence, confusion-matrix counts, and a bootstrap AUC interval.

## 7. Backtest

The test-period strategy enters when the lagged z-score exceeds the configured threshold and exits on convergence, stop-loss, or maximum holding period. PnL at time `t` is generated by the position held from `t-1` over the change in the log spread at `t`.

Each unit of spread turnover trades two asset legs, so transaction costs and slippage are multiplied by two for each position change.

Reported metrics include cumulative net PnL, Sharpe ratio, maximum drawdown, closed-trade count, trade win rate, average holding period, turnover, total costs, profit factor, and block-bootstrap confidence intervals.

## 8. Synthetic regimes

The training spread is calibrated as an AR(1)/OU-style process:

```text
s_t = c + phi s_(t-1) + epsilon_t
```

The calibration estimates the long-run mean, `phi`, innovation volatility, jump probability, jump size, and the common asset-return process. Regime multipliers then alter volatility, mean-reversion speed, jump behavior, and long-run-mean shifts.

The same frozen hedge ratio, selected model, probability threshold, and backtest rules are applied to every synthetic scenario. Performance is summarized by regime.

## 9. Interpretation rule

Strong classification metrics do not establish a profitable strategy. Model metrics and economic metrics are reported separately. A model is considered useful only when its validation-selected implementation improves economically meaningful test-period and robustness outcomes after costs.

## 10. Deterministic regression orientation

The Engle-Granger regression and its residual diagnostics are directional in finite samples. To prevent a cached CSV column order or configuration ticker order from changing results, every unordered candidate pair is converted to a canonical alphabetical orientation before OLS/Engle-Granger estimation. This is a reproducibility control, not a test-period optimization, and is verified by a unit test that reverses all input columns and confirms identical screening results.

## 11. Walk-forward analysis

The final study supplements the fixed chronological split with expanding-window walk-forward validation. Each fold independently repeats:

1. pair screening and multiple-testing control on the fold training window;
2. intercept and hedge-ratio estimation using only that training window;
3. lagged feature construction and convergence labeling;
4. validation-only model and probability-threshold selection across logistic regression, random forest and gradient boosting;
5. untouched out-of-sample trading evaluation.

No future test observations are used to choose the pair, hedge ratio, classifier, or probability threshold.

## 12. Independent backtest verification

The primary backtester uses daily position accounting. A second, independent trade-replay engine reconstructs PnL directly from entry spread, exit spread, direction, and round-trip costs. Exact trade-count and PnL agreement is used as an implementation-validation check. This fulfills the final-project request for a second backtest implementation without introducing a heavy external backtesting dependency.

## 13. Sensitivity analysis

The final pipeline evaluates:

- 10% versus 5% cointegration/FDR significance specifications;
- alternative entry thresholds;
- transaction-cost/slippage levels;
- maximum holding periods;
- a shorter convergence-label horizon;
- chronological test subperiods.

These are robustness analyses. They are not used to retroactively select the best test-period specification.

## 14. Final interpretation rule

A pair can pass statistical cointegration screens and still lose money, while a profitable historical period may not demonstrate incremental ML value. Accordingly, the report separately answers three questions: (1) did the pair satisfy the statistical screen, (2) was the out-of-sample trading path profitable after costs, and (3) did the validation-selected ML filter improve that path relative to the classical baseline?
