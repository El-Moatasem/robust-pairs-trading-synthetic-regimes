# WQU Source Code Development Checklist

This checklist maps the repository to the MScFE 690 Source Code Development guidance.

- [x] GitHub/Bitbucket-ready repository structure.
- [x] `README.md` with project objective, caveats, setup, execution, tests, and outputs.
- [x] YAML configuration files for reproducible synthetic and strict public-data modes.
- [x] `CONTRIBUTORS.md` identifying group contributions.
- [x] `requirements.txt` for `pip install -r requirements.txt`.
- [x] Source modules include docstrings/comments explaining research logic and anti-leakage controls.
- [x] `docs/METHODOLOGY.md` provides mathematical and implementation definitions.
- [x] `docs/PEER_REVIEW_RESPONSE.md` records peer feedback and implemented revisions.
- [x] `docs/RESULTS_AND_SIGNIFICANCE.md` discusses current results, significance, and limitations.
- [x] `docs/M6_PROGRESS_AND_SCHEDULE.md` records progress, remaining tasks, and schedule.
- [x] Unit tests and end-to-end smoke/output verification scripts are included.
- [x] Generated tables/figures in `outputs/` allow the instructor to trace reported results to code.
- [ ] Repository permissions must be set by the group: full access for group members and read-only/reviewer access for the instructor.
- [ ] HTTPS repository link must be placed in the LMS submission or report as required.
